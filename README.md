# Генератор и аналитик данных

Проект генерирует csv-файл с данными, строит по нему html-отчет и позволяет открыть отчет через веб-сервер в Docker-контейнере

## Подготовка

После клонирования репозитория нужно перейти в папку проекта:

```bash
cd docker_bash_tp
```

Сделать главный скрипт исполняемым:

```bash
chmod +x run.sh
```

Все команды ниже нужно запускать из корня проекта.

## Генератор данных

Собрать Docker-образ генератора:

```bash
./run.sh build_generator
```

Запустить контейнер генератора:

```bash
./run.sh run_generator
```

## Локальная генерация данных

Для локальной отладки без Docker можно выполнить:

```bash
./run.sh create_local_data
```

Очистить сгенерированные `.csv` и `.html` файлы из папки `data`:

```bash
./run.sh clear_data
```

Сбор Docker-образа и запуск контейнера репортера:

```bash
./run.sh build_reporter
./run.sh run_reporter
```

Проверить, что контейнер генератора видит локальную папку на хосте:

```bash
./run.sh inside_generator
```

Проверить, что контейнер аналитика видит локальную папку на хосте:

```bash
./run.sh inside_reporter
```

## Запуск HTML-отчета через веб-сервер

Перед запуском веб-сервера нужно создать отчет:

```bash
./run.sh build_generator
./run.sh run_generator
./run.sh build_reporter
./run.sh run_reporter
```

Затем запустить сервер:

```bash
./run.sh report_server
```

Эта команда запускает контейнер на образе `nginx:alpine`, который скачивается автоматически с Dockerhub.

## Как открыть отчет в GitHub Codespaces

1. Запустите сервер:

```bash
./run.sh report_server
```
2. Пока активен контейнер перейдите по ссылке: https://localhost:8080/report.html

Команда `report_server` продолжает работать, пока запущен контейнер. Чтобы остановить сервер, нажмите в терминале:

```text
Ctrl + C
```
